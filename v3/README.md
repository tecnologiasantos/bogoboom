# Bogoboom v3

Recomeço do projeto, a partir da ideia original (sem código herdado da v1/v2).

Páginas estáticas, sem build: abra `index.html` ou rode `python3 -m http.server` dentro desta pasta.

- `index.html`, `styles.css`, `app.js`: página inicial (EN / ES / PT)
- `assets/logo-mark.svg`: marca; `assets/original-concept.jpeg`: imagem de referência
- O formulário da lista de espera abre o app de e-mail (ainda sem backend)
